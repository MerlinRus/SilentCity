# После дождя

Маленький интерактивный ночной город: дождь, эмбиент-музыка, локальный блокнот, таймер на 25 минут и записки жителей.

Репозиторий проекта: https://github.com/MerlinRus/SilentCity. Рабочий каталог — `new`, публикация сайта — `/opt/after-rain` на сервере.

## Запуск

Нужен Node.js 18 или новее. В этой папке выполните `npm start`, затем откройте http://127.0.0.1:4173. Устанавливать зависимости не нужно. Другой порт: переменная окружения `PORT`.

Нажмите «Побыть здесь» или кнопку воспроизведения, чтобы включить звук. Светящиеся метки на зданиях открывают радио, заметки и таймер. `M` включает и выключает звук, `F` переключает полный экран, `Escape` закрывает окно или возвращает заголовок. На телефоне доступны те же кнопки.

Три звуковые сцены: кафе с эмбиентом, стук колёс и морской прибой. Записи CC0 лежат в `sounds/`, загружаются при выборе станции и воспроизводятся через HTML Audio с плавным переходом через Web Audio. Полные записи не декодируются в память заранее. Авторы и источники указаны в `sounds/credits.html`. Только мягкие ноты кафе синтезируются на устройстве; генератора белого шума нет. Заметки сохраняются в localStorage этого браузера; очистка данных сайта удалит их. Для загрузки шрифта Golos Text используется Google Fonts; без сети работает системный шрифт.

«Свой микс» смешивает камин, гром, ветер, сверчков, Петербургское метро, настоящий дождь и выбранную радиоволну. Каждый слой можно выключить отдельно; «Выключить всё» останавливает всё воспроизведение. Уровни сохраняются в localStorage без автоматического старта при следующем визите. Генератор шумового дождя удалён: дождь в аудио по умолчанию выключен. Дождь на иллюстрации остаётся визуальным эффектом.

`npm run check` проверяет синтаксис JavaScript. Сцена нарисована SVG, дождь — Canvas. Настройка уменьшения движения учитывается. Таймер работает по времени окончания и восстанавливает верное оставшееся время после фонового режима, но не переживает перезагрузку страницы.

## Лёгкая сцена и жизнь в окнах

Дождь рисуется не чаще 30 кадров/с, в Canvas с разрешением 1× CSS-пикселей независимо от DPR экрана. Число капель зависит от площади экрана (80–250 до применения интенсивности); линии объединены в три прохода по прозрачности, без создания массивов на кадр. Свечение окон — SVG-градиенты вместо Gaussian Blur. Панель и подложка диалогов не используют backdrop-filter.

При открытом диалоге, скрытой вкладке и уходе со страницы дождь и переключение окон останавливаются. Звук не прерывается при чтении записки. На общей паузе AudioContext приостанавливается после затухания. При `prefers-reduced-motion` дождь статичен, окна не переключаются автоматически.

Три окна с конвертами по очереди загораются раз в 18 секунд. Нажатие на окно или «Кто ещё не спит?» открывает короткую вымышленную записку Лены, Миши или Сони; «Другое окно» листает жителей. Всего 36 записок — по 12 у каждого. Записка выбирается случайно из непрочитанных; новый круг для жителя начинается только после всех его записок, без немедленного повтора последней. История хранится в `after-rain-resident-notes-v1` в localStorage (не более 36 идентификаторов); запись считается прочитанной только при открытии. При новом заходе первым загорается окно другого жителя. Если хранилище недоступно, чередование работает в пределах текущей страницы; очистка данных браузера сбрасывает историю.

Тексты включены в существующий app.js: дополнительных запросов, библиотек, таймеров и SVG-элементов нет, в DOM остаётся только открытая записка. Лампы, конверты и комнатные иллюстрации — SVG, записки остаются доступным текстом. Используется существующий нативный dialog с закрытием по Escape и возвратом фокуса; автопоказов нет.

Логика эффектов проверена с управляемыми часами: 30 отрисовок в секунду при 60/120 Гц, 28 при 144 Гц, три вызова stroke на кадр, отсутствие циклов в диалоге/фоне и при reduced motion, один цикл после повторного возобновления. Это проверка планировщика, не замер FPS на физическом старом телефоне.

## Мобильная версия

Все иконки, стрелки и пиктограммы рисуются SVG-контурами. Не использовать эмодзи, символьные иконки, иконочные шрифты или `<text>` для пиктограмм внутри SVG: их отрисовка зависит от системного шрифта телефона. Текстовые названия и подписи остаются текстом.

`mobile.css` адаптирует город под портретный и горизонтальный экран, включая iPhone 17 Pro. Панель использует `100dvh` и safe-area insets. Окна открываются как нижние панели; в микшере список прокручивается отдельно от кнопок воспроизведения. Visual Viewport API ограничивает высоту окна при изменении доступной области, а шрифт блокнота 16 px предотвращает автоматическое увеличение поля ввода в Safari. Масштабирование страницы пользователем остаётся доступно.

Компоновка проверена в Chromium на 402×714, 402×874, 874×338, 320×568 и 1280×820; проверены перетаскивание ползунка, прокрутка списка и уменьшенная высота блокнота. Физический iPhone и Safari в этой среде недоступны: вырез, домашний индикатор, экранная клавиатура и реальные touch-жесты требуют проверки на устройстве.
