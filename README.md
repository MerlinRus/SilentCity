# После дождя

Маленький интерактивный ночной город: дождь, эмбиент-музыка, локальный блокнот, таймер на 25 минут и записки жителей.

Репозиторий проекта: https://github.com/MerlinRus/SilentCity. Рабочий каталог — `new`, публикация сайта — `/opt/after-rain` на сервере.

## Запуск

Нужен Node.js 18 или новее. В этой папке выполните `npm start`, затем откройте http://127.0.0.1:4173. Устанавливать зависимости не нужно. Другой порт: переменная окружения `PORT`.

Нажмите «Побыть здесь» или кнопку воспроизведения, чтобы включить звук. Светящиеся метки на зданиях открывают радио, заметки и таймер. `M` включает и выключает звук, `F` переключает полный экран, `Escape` закрывает окно или возвращает заголовок. На телефоне доступны те же кнопки.

Три звуковые сцены: кафе с эмбиентом, стук колёс и морской прибой. Записи CC0 лежат в `sounds/`, загружаются при выборе станции и воспроизводятся через HTML Audio с плавным переходом через Web Audio. Полные записи не декодируются в память заранее. Авторы и источники указаны в `sounds/credits.html`. Только мягкие ноты кафе синтезируются на устройстве; генератора белого шума нет. Заметки сохраняются в localStorage этого браузера; очистка данных сайта удалит их. Для загрузки шрифта Golos Text используется Google Fonts; без сети работает системный шрифт.

«Свой микс» смешивает камин, гром, ветер, сверчков, Петербургское метро, настоящий дождь и выбранную радиоволну. Каждый слой можно выключить отдельно; «Выключить всё» останавливает всё воспроизведение. Уровни сохраняются в localStorage без автоматического старта при следующем визите. Генератор шумового дождя удалён: дождь в аудио по умолчанию выключен. Дождь на иллюстрации остаётся визуальным эффектом.

`npm run check` проверяет синтаксис JavaScript. Сцена нарисована SVG, дождь — Canvas. Настройка уменьшения движения учитывается. Таймер работает по времени окончания и восстанавливает верное оставшееся время после фонового режима, но не переживает перезагрузку страницы.

## Лёгкая сцена и жизнь в окнах

Дождь рисуется не чаще 30 кадров/с, в Canvas с разрешением 1× CSS-пикселей независимо от DPR экрана. Число капель зависит от площади экрана (80–250 до применения интенсивности); линии объединены в три прохода по прозрачности, без создания массивов на кадр. Свечение окон — SVG-градиенты вместо Gaussian Blur. Панель и подложка диалогов не используют backdrop-filter.

При открытом диалоге, скрытой вкладке и уходе со страницы дождь и переключение окон останавливаются. Звук не прерывается при чтении записки. На общей паузе AudioContext приостанавливается после затухания. При `prefers-reduced-motion` дождь статичен, окна не переключаются автоматически.

Три окна с конвертами по очереди загораются раз в 18 секунд. Нажатие на окно или «Кто ещё не спит?» открывает короткую вымышленную записку Лены, Миши или Сони; «Другое окно» листает жителей. Всего 36 записок — по 12 у каждого. Записка выбирается случайно из непрочитанных; новый круг для жителя начинается только после всех его записок, без немедленного повтора последней. История хранится в `after-rain-resident-notes-v1` в localStorage (не более 36 идентификаторов); запись считается прочитанной только при открытии. При новом заходе первым загорается окно другого жителя. Если хранилище недоступно, чередование работает в пределах текущей страницы; очистка данных браузера сбрасывает историю.

Тексты включены в существующий app.js: дополнительных запросов, библиотек, таймеров и SVG-элементов нет, в DOM остаётся только открытая записка. Лампы, конверты и комнатные иллюстрации — SVG, записки остаются доступным текстом. Используется существующий нативный dialog с закрытием по Escape и возвратом фокуса; автопоказов нет.

Логика эффектов проверена с управляемыми часами: 30 отрисовок в секунду при 60/120 Гц, 28 при 144 Гц, три вызова stroke на кадр, отсутствие циклов в диалоге/фоне и при reduced motion, один цикл после повторного возобновления. Это проверка планировщика, не замер FPS на физическом старом телефоне.

Кнопка «Ещё записка» выбирает непрочитанный текст того же жителя, не закрывая диалог. Меняются только заголовок и текст: SVG-иллюстрация, кнопки и фокус сохраняются. Изменение текста объявляется через aria-live. «Другое окно» по-прежнему переключает жителя; обе пиктограммы — SVG-контуры.

## Плавные переходы

Вход в «Исследовать город» плавно приближает город, выход отдаляет его за 280 мс. Завесы и затемнения больше нет: один существующий SVG временно размещается в неподвижной области экрана, Web Animations API меняет только его transform/opacity. Начальная и конечная камеры измеряются один раз через [getScreenCTM](https://developer.mozilla.org/en-US/docs/Web/API/SVGGraphicsElement/getScreenCTM), включая реальные пропорции SVG и прокрутку; размеры и scroll не пересчитываются по кадрам. При выходе зум начинается с того места, куда пользователь передвинул город. Повторное переключение продолжает движение от текущей видимой камеры. По завершении удаляются анимация и временная компоновка, восстанавливается нативная прокрутка без скачка.

Дождь и автоматическая жизнь города на эти 280 мс приостановлены; звук не меняется. Escape/клавиатура, reduced motion, открытие окна, resize и уход со страницы завершают переход сразу. Без Web Animations API или getScreenCTM режим переключается без движения. SVG не клонируется, нет новых запросов, библиотек, постоянных таймеров, покадрового JS и постоянного will-change. Плавность и расход графической памяти на физическом старом телефоне требуют отдельной проверки.

HUD мягко исчезает и возвращается за 250 мс, кнопки слегка поддаются нажатию. Нативные диалоги плавно появляются и закрываются: на телефоне — снизу, на десктопе — с небольшим приближением. Используются CSS `@starting-style`, `display`/`overlay` с `allow-discrete` по [рекомендации MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog#animating_dialogs); в старых браузерах диалог открывается и закрывается сразу, сохраняя нативный фокус и Escape.

При смене жителя/вкладки или новой записке короткий переход Web Animations API длится 180 мс. Текст и действия обновляются сразу, без ожидания анимации; повторное действие отменяет предыдущий эффект. Клавиатура и `prefers-reduced-motion` отключают новые переходы. HUD в режиме исследования сразу становится inert, поэтому исчезающие кнопки не перехватывают фокус. Новых библиотек, SVG-элементов, запросов, постоянных таймеров и покадрового JS нет; двигаются только transform/opacity небольших поверхностей, не весь город. Поддерживающие свойства display/overlay/visibility переключаются дискретно, без покадрового изменения размеров.

## Жизнь во дворе

Кот на подоконнике изредка поворачивает голову или прячется за штору; свет в подъезде включается на 18 секунд. Трамвай проходит за домами за 18 секунд: первый раз примерно через 36 секунд, затем раз в три минуты видимого времени без диалогов. Велосипед у кафе, забытый зонт и кораблик в луже — статичные SVG-детали. Новых изображений, запросов, библиотек и покадрового JavaScript для этих деталей нет.

Все события используют существующий один timeout с шагом 18 секунд. Движение трамвая — однократная CSS-анимация transform/opacity; по завершении она удаляется. В фоне и открытом диалоге цикл останавливается, а трамвай приостанавливается. При reduced motion события не запускаются: кот и трамвай остаются статичными.

После полуночи обычные окна гаснут тремя группами: в 00:00, 00:20 и 00:40, до 06:00. Используется местное время браузера и существующее обновление часов; в фоне свет не меняется. Кафе, фонари, кот и все интерактивные окна не затрагиваются.

## Мобильная версия

Адаптив проверяется по CSS-размерам viewport, а не физическому разрешению матрицы. Основные настольные варианты: 1280×720, 1920×1080, 2560×1440 и 3840×2160. Основной текст/управление/подписи: 18/16/14 px на компактном десктопе, 20/18/16 px на Full HD и 2K, 24/20/18 px на 4K (при стандартном базовом размере браузера). Размеры заданы в rem; масштаб браузера и настройки шрифта не блокируются. Основание шкалы — [USWDS typography](https://designsystem.digital.gov/components/typography/) и [web.dev typography](https://web.dev/learn/design/typography/), а не единый магический размер для физического «2K».

На телефонах и планшетах есть «Исследовать город»: скрывает HUD, не меняя звук, и открывает увеличенную SVG-сцену в нативном двумерном scroll-контейнере. Город можно двигать пальцем, колесом/трекпадом или клавишами; зоны нажатия окон увеличены. «Вернуть интерфейс» и Escape выходят из режима; закрытие записки оставляет пользователя в городе. Новых библиотек, сетевых запросов, таймеров, pointermove-обработчиков и покадрового JS нет. Увеличение страницы остаётся доступно. Реальные iOS/Android-жесты, safe areas и клавиатуру нужно дополнительно проверить на физическом устройстве.

Проверены 18 CSS-разрешений в Chromium: 1280×720, 1366×768, 1920×1080, 2560×1440, 3840×2160, 320×568, 360×640, 375×667, 390×844, 402×874, 412×915, 430×932, 480×854, 720×1280, 768×1024, 820×1180, 1024×768 и 844×390. Проверены отсутствие горизонтального переполнения HUD, доступность его кнопок, крупные зоны окон (на 320 px — от 61 px), нативная горизонтальная прокрутка колёсиком, записки, Escape и возврат фокуса. Это не проверка физических touch-жестов в Safari.

Все иконки, стрелки и пиктограммы рисуются SVG-контурами. Не использовать эмодзи, символьные иконки, иконочные шрифты или `<text>` для пиктограмм внутри SVG: их отрисовка зависит от системного шрифта телефона. Текстовые названия и подписи остаются текстом.

`mobile.css` адаптирует город под портретный и горизонтальный экран, включая iPhone 17 Pro. Панель использует `100dvh` и safe-area insets. Окна открываются как нижние панели; в микшере список прокручивается отдельно от кнопок воспроизведения. Visual Viewport API ограничивает высоту окна при изменении доступной области, а шрифт блокнота 16 px предотвращает автоматическое увеличение поля ввода в Safari. Масштабирование страницы пользователем остаётся доступно.

Компоновка проверена в Chromium на 402×714, 402×874, 874×338, 320×568 и 1280×820; проверены перетаскивание ползунка, прокрутка списка и уменьшенная высота блокнота. Физический iPhone и Safari в этой среде недоступны: вырез, домашний индикатор, экранная клавиатура и реальные touch-жесты требуют проверки на устройстве.
